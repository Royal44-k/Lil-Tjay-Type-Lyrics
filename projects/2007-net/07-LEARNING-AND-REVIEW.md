# 2007.net — 研究转化与制作复盘

日期：2026-09-29。这里记录可复用的方法、证据范围与下一轮需要实际试听回答的问题。它是本项目的知识记录，尚未运行会话外的自动跟踪。

## 年代依据

Pew 在 2007 年公布的调查显示，个人主页、给朋友留言、私信和公开呈现朋友关系已经是美国青少年网络生活的一部分；这支持把“页面怎样改变相处”作为故事背景。调查对象是青少年，本专辑人物设定为成年人，不能把调查百分比直接套到角色所属人群。[Pew：Social Networking Websites and Teens](https://www.pewresearch.org/internet/2007/01/07/social-networking-websites-and-teens/)

同年研究也记录了网页、博客与其他内容制作活动。对创作有价值的细节是：使用者可以主动改变自己的页面，也可以为朋友制作内容；因此歌曲写自制背景、demo 和照片，而不只写被动刷屏。[Pew：Teens and Social Media](https://www.pewresearch.org/internet/2007/12/19/teens-and-social-media/)

danah boyd 的 2006 年研究说明，MySpace 的 Top 8 会把一组朋友放在主页显眼位置，并讨论个人资料怎样参与身份呈现。《TOP EIGHT》的具体争吵为本项目虚构，社会机制有同期研究依据。[boyd：Identity Production in a Networked Culture](https://www.danah.org/papers/talks/AAAS2006.html)

年代写作约束：前六首围绕桌面网页、文件、相机闪光、光盘和消息展开。没有把当代短视频推荐页、Story 阅后即焚或统一的已读回执写进 2007 年日常。07 明确回到 2026，才讨论是否重新发布旧照片。2007.net 是专辑名，没有注册或启用相应网站。

## 从参考到原创：本轮积累

| 方法 | 在本张采用的做法 | 后续必须用听感验证的事 |
|---|---|---|
| 可记住的旋律入口 | 七首都只先确定一个短核心 Hook 动机 | 不看歌词听两遍后，是否能复唱标题和节奏 |
| sampling | 自写 K01 与 S01，再采自己的实际录音 | 切片是否改善律动，还是遮挡咬字 |
| voice reuse | VQ01 在期待、亲密、无回复、今天的回答之间变化 | 相同声源是否可辨，是否仍像人物而非随机装饰 |
| rearrangement | K01 在 94 完整演奏、132 切分、86 留白 | 共用音高是否真的形成不同 groove |
| orchestration | 各曲限制中心音色，按角色接力增加或撤掉声部 | 第二个主唱开口时是否获得清楚的空间 |
| 类型混合 | 02/04 尖锐，03/05 亲近，06 跳动，07 收束 | 连续播放是否有情绪起伏，切换是否过于生硬 |
| 歌词叙事 | 让外套、鞋子、合照、草稿跨曲改变意义 | 独立播放仍可懂，连听能发现更多信息 |

这些是创作假设，当前没有把它们写成已经证明的听众反应或商业成绩。也不以添加某个艺人的名字作为人声质量的解决方式。

## 英文与表演检查

- SCREEN NAME：screen name 两个清楚重音；slow/glow 留给旋律，Verse 不能每句都用同一上扬尾音。
- TOP EIGHT：eight、day、page、face 的 /eɪ/ 要清楚。男声的急躁、女声的直接、桥段的承认分别处理。
- LOW-RES KISS：low-res-kiss 三音节；distance 两音节。清楚唱出 humor 与触感，保留笑意而不持续气声。
- POP-UP HEAVEN：pop-up-heav-en 四音节；click-click 两次干净的短音。长第二段按两小节一句，不能为了快而丢信息。
- DRAFTS AT 3:17：three-se-ven-teen 四音节；sorry 不拖成炫技。三次认错动作是写、承认没发、后续真的发送，不能合并成即时被原谅。
- BURN THIS SUMMER：burn-this-sum-mer 四音节；copy、count-in、skipping 不吞音。女声工作选择的段落避免唱成悲伤告别。
- 2007.NET：开场读 two-thou-sand-se-ven-dot-net。I was here 与 I'm still here 区分时态；末尾正常对话比宏大尾奏更重要。

## 候选选择与迭代

第一组建议先制作 LOW-RES KISS 与 TOP EIGHT，检查温暖的人声和高能量鼓组能否属于同一张唱片；之后制作 SCREEN NAME 与 07，确定两种时间的人声距离；再完成中段和 06。此顺序是工作优先级，正式曲序保持不变。

每首先比较两个完整候选。歌词漏句、声部错位或核心 Hook 不成立时，优先修对应问题；已经成立的歌曲无需为了尝试而反复生成。实际工具只支持部分编辑时，按其可用功能操作；精确复用与多声部组装可交给 DAW。

| 检查项 | 可操作的通过条件 |
|---|---|
| 歌词 | 对照全文，无关键叙事遗漏；02/03/06 两个角色可分辨 |
| Hook | 标题清楚；至少一位首次试听者能在两遍后复述节奏或旋律；记录结果，不预填通过 |
| Flow | 长句不靠过快吞音塞进一小节；句尾有自然气口 |
| 采样 | 能指出源文件与剪辑位置；没有把新 take 称为同一录音 |
| 混音 | 低音量与单声道检查仍能听清主唱；808 与 kick 各有空间 |
| 专辑 | 03/05 提供真实喘息；06 有快乐；07 的收束不重复前两张专辑的结尾故事 |
| 交付 | 音频制作后补实际速度/调性/时长、录音署名、素材许可、版本号与发行规格 |

商业定位是待验证的判断：LOW-RES KISS 的短副歌适合先测试旋律接受度，TOP EIGHT 的对话与换位适合表现团队角色，BURN THIS SUMMER 适合现场合唱。这里没有预测播放量、榜单或收入。
