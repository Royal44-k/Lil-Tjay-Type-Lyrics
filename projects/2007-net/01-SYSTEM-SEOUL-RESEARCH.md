## 2. 《너》能确认什么

《너》在 SS-POP 1 中列第三首、标题曲，平台艺人署名 SYSTEM SEOUL 与 ycs。正式制作信息为：作词 **ycs**；作曲 **djmendos、ycs、sehunonline**；编曲 **djmendos、ycs**。Genie 写作 dj mendos，Bugs 写作 djmendos。正式 MV 的艺人频道标题为 **ycs - 너 (Official Video)**，发布于 2025-09-03；说明栏另列 Djmendos 制作、410kiye 导演、kyon 剪辑与视觉效果。[Genie 专辑目录](https://www.genie.co.kr/detail/albumInfo?axnm=87413425)、[Bugs 歌曲 credits](https://music.bugs.co.kr/track/6445300)、[艺人官方 MV](https://www.youtube.com/watch?v=TiOpGgCXeT0)

从公开歌词文本可以作出的文学解读是：人物在逞强、恳求和失去后的自我否认之间来回摆动，反复回到同一段关系；韩英混合与口语使表达带有私人留言感。这是对文本的解释，不能延伸为艺人的真实经历。对《2007.net》可用的启发是：让 Hook 保留一个明确的情绪矛盾，让 Verse 补充具体事件；不要把伤心简单等同于抽象的空虚或炫耀。[歌词文本及署名](https://music.bugs.co.kr/track/6445300)

## 3. 风格与创作方法：事实、评论和推导分开

此次检索未获得足以核实的主创长访谈。不能把“他们专门重建 2007 年互联网”或“使用某一套制作软件”写成团队自述。

可引用的外部观察来自朴胜民于 2026-08-14 发表的 IZM 评论：作者将其吸引力联系到怀旧与 digicore，指出第三作中的短促 hardcore/Gabber 转换和 ycs 的旋律写作，也批评扩张篇幅后的重复。这些是评论者判断，适合用作需要在新项目中检验的问题。[IZM《SS-Pop 3》评论](https://www.izm.co.kr/posts?id=34160)

由此形成《2007.net》的四项制作原则，以下均为本项目原创决策：

1. **先让旋律和人物成立。** 每首先用普通钢琴或清唱检验 Hook。去掉效果仍然有记忆点，才增加切片、共振峰变化和失真。
2. **采样承担叙事功能。** 先创作并录制自己的“旧素材”，再重排成记忆碎片。音质压缩可以代表距离，完整再现可以代表人物终于听清某句话；不凭随机爆音制造年代感。
3. **同一声音在不同情境改变意义。** 给同一原创人声留存干声、切片和调性变体；本项目在开场完整唱出提问，03 将其置于亲密背景，05 留出没有回答的空白，07 加入今天的新回答。复用的是有记录的素材，角色变化则由新歌词与表演完成。
4. **强烈段落服务专辑弧线。** 将尖锐数码失真集中到《POP-UP HEAVEN》等压力节点；《LOW-RES KISS》《DRAFTS AT 3:17》为呼吸、人声与细节留空间；终曲用较清楚的音色回到现在。

## 4. 与《2007.net》七首歌的连接

| 原创曲目 | 本项目采用的研究启发 | 写作重点 |
|---|---|---|
| SCREEN NAME | 网络身份与亲密口语；原创声纹首次出现 | 一个昵称怎样让人敢于说真话 |
| TOP EIGHT | 抓耳重复与细小心理转折 | 被公开排名的友谊，与排名之外的照顾 |
| LOW-RES KISS | 柔和器乐循环与直接的旋律表达 | 低清照片没有保存住的真实触感 |
| POP-UP HEAVEN | 高反差电子段落和节奏重排 | 好奇、欲望与注意力被出售的临界点 |
| DRAFTS AT 3:17 | 人声留白；同一短句更换语境 | 未发送的话如何保护人，也如何困住人 |
| BURN THIS SUMMER | 怀旧素材经由新编排转化 | 给朋友刻下一段时间；记忆并不归一个人所有 |
| 2007.NET | 回收前面的小动机，让它们长成完整表达 | 2026 年的成年人重新理解自己保存的 2007 年 |

“2007”是人物档案的年份，“digicore / hyperpop / 当代 melodic trap”是从今天回望它的声音语言。宣传时应明确这是当代创作对旧互联网经验的重构；不把这些当代标签写成 2007 年当时的类型名称。声音参考不等于复用 SYSTEM SEOUL 的旋律、歌词、正式录音或真实艺人人声。

## 5. 后续研究记录方式

每次新增参考保留发布日期、版本、署名、直接来源、已确认事实与未确认问题。完成音频后再记录实际听检结果：人声是否清楚、Hook 是否可复述、片段复用是否改变意义、七首的能量是否有起伏。本文件建立可继续更新的制作知识记录，不代表已开启自动监测或在会话之外持续学习。
