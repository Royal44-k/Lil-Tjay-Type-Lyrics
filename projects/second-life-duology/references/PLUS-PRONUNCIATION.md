# 发音与重音检查

当前是书面演唱设计，不是已听检通过的真人演唱。默认保留自然英文拼写；只有实际输出读错时，再在 Suno 副本中做最小音节提示。发行歌词仍保留标准拼写。

| 词或短句 | 本稿意图 | 操作 |
|---|---|---|
| receipt | /rɪˈsiːt/，重音 CEIPT，p 不发音 | 先用原拼写；读错再试 re-seat，仅改生成副本 |
| Ivory | Hook 分为 I-vo-ry 三个歌唱音节，重音 I | Hook MIDI 已分音节；若生成压成两音节影响旋律，再试 I-vo-ry |
| hours | /aʊərz/，本 Hook 压为一个歌唱音节 | 不强制拖出额外重拍 |
| Counterstep | COUN-ter-step；COUN 主重音，step 次重音 | 这是本项目标题，读成 counter + step，不读作三等重音 |
| Fast-forward | FAST-FOR-ward，保留两次同型小动机 | 末尾 ward 轻，三次 wait 独立 |
| quiet | QUI-et，两音节 | 两次下行，不挤成一音节 |
| bass / low end（若生成时替换歌词用到） | 低频意义读 /beɪs/ | 本稿主要写 low end；制作说明里的 bass 不进歌词栏 |
| live / read / lead / wind 等同形异音词 | 以具体歌词句意决定 | PRONUNCIATION-FLAGS.csv 是检索提示，不代表已发现发音错误；先听，再修 |

Function words（the、a、of、to、and 等）通常轻放，重要名词和动词获得持续时间与旋律位置。说唱允许切分、弱起和跨小节，不要求所有重音机械地落在第一或第三拍。

## 主歌拍位如何使用

VOCAL-MAP.csv 分配的是“这一行拥有多少小节”，不是把每个词平均分进网格。140–156 的快拍曲通常一行两个快小节；76/88 的慢速曲通常一行一个常规小节。两者的实际说话时间相近。

每段排练先自然读句子，再对照 PRODUCTION.md 标出的重点词打拍。某行必须吞字才唱得完，就先改节奏、缩短装饰或局部改词，并更新文件版本；不因书面词数通过就认定演唱通过。
