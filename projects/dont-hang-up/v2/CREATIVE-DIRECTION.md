# DON'T HANG UP — v2 制作方案

## 主题与人物

一个正在上升的音乐人，可以面对满场观众，却不习惯向亲近的人承认疲惫。他把“我挺好的”学得太熟，也把独立误用成了疏远。故事从他需要有人接电话，走到他能听见对方相同的掩饰。

情绪落点：陪伴未必马上解决生活，但能让一个人第一次关掉电视睡觉。Bridge 的 “Call me tomorrow / Even if you're alright” 把联系从危机时的求助扩展到日常。

## 氛围与声音

深夜酒店的冷光 → 空房子的电视光 → 清晨厨房。克制、私密、略带疲惫，最后多一点空气与温度。148 BPM / 74 半拍体感，C minor，4/4。

男声：自然美式英语，明亮但带疲惫感的男高音。Verse 在 G3–E♭4 附近收窄，采用有音高的短句 rap；Hook 打开到 G4，用长元音形成旋律。女声：轻声、中高音、近距离录音，完整唱出原创母句后制作切片。音域是写作起点，录音时可整体移调。

## 韵脚与句式

| 段落 | 韵链 | 叙事任务与节奏 |
| --- | --- | --- |
| Verse 1 / 1–4 | light / flight / lines / mine：/aɪ/ | 物件短句转向完整复句；台上的熟练与电话中的语塞 |
| Verse 1 / 5–8 | hearts / part；her / hurt | 两句简短动作，再跨行讲述从母亲身上学会的忍耐 |
| Verse 1 / 9–12 | black / back / bad / cracks：/æ/ | 自我矛盾后接直接引语与反问；重拍落 distance / mad / back |
| Verse 1 / 13–16 | head / yet / breath / said：/ɛ/ | 准备好的长篇解释被一句日常关心打断 |
| Verse 2 / 1–4 | plastic / habits / fabric / standin'：/æ/、/ɪ/ 近韵 | 家具和站着吃饭的动作承载落差，不额外解释孤独 |
| Verse 2 / 5–8 | straight / playin' / place / safe：/eɪ/ | 电视、重播、门锁：物质控制和内在安全感的距离 |

| Verse 2 / 13–16 | soft / off；goodnight / time | 两个韵组使结尾放慢；以行为变化收束 |

这些韵链包含近韵和元音押韵。演唱时突出共同的重读元音，弱读连接词，不为了纸面工整扭曲英语发音。逐音节 MIDI 表达建议的入口、落点和留白；真人演唱应保留连音及自然变化。

## 旋律与结构

Hook 标题：G3–C4–E♭4 / G3–B♭3–C4。第二组标题提高重心。UP 保留长音，女声回答落在男声停顿后。女声母句为两条相连短句：G4–B♭4–C5–B♭4–G4 / G4–B♭4–E♭5–D5–C5。

Verse 1 开始用窄音域、短断句；母亲段落减少跳进；第三组连续近韵靠节奏推动，末组降低力度。Verse 2 首段少鼓、少 hat；回应对方来电时稍抬旋律；最后一行回 C，让下一段的留白成立。

曲式：Intro 4 / Hook 16 / Verse 1 16 / Pre 4 / Hook 16 / Verse 2 16 / Bridge 8 / Final Hook 16 / Outro 4。共 100 个 148 BPM 小节，约 2:42，另加短尾音。首 Hook 约 0:06.5。

## Beat 与采样制作

Cm9 → A♭maj7 → E♭maj7 → G7sus4 / G7，段尾提前回 Cm9。柔和键盘与短音拨弦构成上部，808 负责重量，军鼓落半拍，hat 的滚奏集中在句尾。

女声需要三种轨道：完整母句、有词短切片、没有辅音的尾音氛围。母句录好后再剪，不逐词拼接假唱。开头与 Bridge 放完整句；Hook 放短回答；叙事密集处仅留尾音。

伴奏中给主唱中心频段留空间；填充鼓避免盖住歌词入口。Final Hook 的增加优先来自真人复唱和回应关系，编曲只略加宽。
