# DON'T HANG UP

原创英文 melodic trap 词曲初稿与制作资料，2026-09-17。

148 BPM（74 半拍体感）· C minor · 约 2:42 · 女声采样母句与男声 Hook 对答。

故事由“今晚请别挂断”推进为“下次我也会接住你”。参考研究来自 Lil Tjay《Scared 2 Be Lonely》；本项目的词句与 MIDI 音符独立创作。

## 使用顺序

1. 读 `DONT-HANG-UP.md`：完整英文歌词、clean alternate、演唱方向与曲式。
2. 将 `dont-hang-up-hook.mid` 导入 DAW：包含四小节 Intro 与十六小节 Hook。钢琴和颤音琴轨分别代表男声与女声待录旋律，不是人声录音。
3. 读 `PRODUCER-BRIEF.md`：采样母句录制、切片、和声、808、鼓组与段落变化。
4. 用 `dont-hang-up-composition.mid` 查看全曲结构与三个 Hook。Verse 有完整歌词及编排位置，主唱音高尚未逐字谱写。
