# DON'T MAKE IT COOL

DBE03 · 104 BPM · A major · 4/4 · 56 小节 · 计划 2:09

风格：R&B / singing rap / syncopated hip-hop。能量目标：6/10。当前状态：完整词曲预制作，音频与演唱听检待完成。


## 人物与命题

两个人都以轻松掩饰认真。男声承认借充电器只是借口，女声指出自己也做了准备，并把 vague 的 maybe 改成具体的 Friday。


## 主歌如何推进

猜测和装酷 → 各自暴露小动作 → 女声拿到叙事权 → 约定具体时间。没有把暧昧的对方写成等待被攻略的奖品。


## 韵脚与内部节奏

Hook cool/truth/smooth/too 围绕 /uː/。tilt/hits、reason/building（松散，借顺口节奏）、percent/been；favor/favorite、up/cup、weekend/mean it、mood/you，女段用交叉近韵。


## 演唱与重音

104 BPM 主歌每行一小节，长句用轻唱快念，不把 coincidence 的每个音节拖长。Chorus 每行两小节。Bridge 前两句男声、后两句女声；Post 全女声，I’d LIKE to 的 LIKE 是情绪重音。


## 编曲动作

Intro 只有两小节，副歌尽早进入。Verse 2 用相同 bass 但撤掉 guitar，让女声不被配器掩盖。Bridge 一行一小节，结尾留半拍给笑意。Post 以短回应结束，不另加一轮完整副歌。


## 采样与配器

EP03 四小节原创新电钢琴源谱；录制后可切成短和弦起音并重排。左右手分开只是演奏参考，实际踏板的连续性由录音决定。


## 优先听检问题

主歌密度是本曲主要风险，宁可更接近说唱，也不要吞掉 eighty percent 和 green one。声部串位时先分段修，不靠真实歌手名字提示。


## Hook 与节拍资产

Amaj9 → C#m7 → Dmaj9 → E13。每个和声两个网格小节。HOOK-GUIDE.mid 包含主旋律、和声、根音参考；不是已经录制的人声或完整伴奏。主歌由 VOCAL-MAP.csv 分配角色和小节，主歌完整音高表演在 Suno 或演唱排练时定稿。DRUM-GRID.csv 是八小节起始鼓型，非从参考歌曲转录。

MusicXML 为可编辑主旋律谱，门限按十六分音符量化；MIDI 保留更细时值。歌手可整曲移调，须同步修改器乐与版本记录。
