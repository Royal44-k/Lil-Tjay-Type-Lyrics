# 分阶段交付与验收

本轮承接此前由用户自行操作 Suno 的制作分工，目标是七首完整作品的预制作资产。没有将“生成音频、实际试听、混音母带、发行”缩写成已完成。下列阶段分别签核。

## A — 本轮词曲资料

| 要求 | 证据 | 验证范围 |
|---|---|---|
| 研究《Destined 2 Win》背景与歌词含义 | RESEARCH-DESTINED-2-WIN.md，唱片公司、访谈与授权文本来源 | 区分事实、作者自述、本项目解读；不冒充音频听审 |
| 生活启示与艺术魅力 | 研究第 3–5 部分、ALBUM-DIRECTION.md | 具体解释野心、关系、失去与选择，避免只写成功宣言 |
| 七首原创英文歌曲 | 七个 LYRICS.txt / SONGBOOK.md | 重复段全部展开，人物视角、语法、韵脚书面审查 |
| D1fferent 与 chosen one | 首曲、尾曲歌词与专辑方向 | 标题用 1，实际演唱 different；身份在故事中变化 |

脚本检查歌词词数 180–650、Style ≤1000 字符，是本项目的内部合理性门限，不宣称 Suno 官方硬性限制，不替代听检。MusicXML 只按 XML 结构与每小节总时值校验，未声称经过排版软件逐页审阅或具备出版级雕版质量。

## B — Suno 草样

必须听检：标题是否清晰可复唱、整曲歌词有无遗漏/加词、句法重音是否自然、密集句是否吞字、角色是否正确、第二段是否增加事件、原定器乐是否真正起到采样/回答的作用、尾音是否完整。

本项目的“抓耳”验收办法：不看歌词听一次核心段，短暂离开播放后尝试哼回标题节奏；记录实际能记住什么，不由 MIDI 存在直接推断魔性或商业成绩。最好让不熟悉创作稿的听者参与。主打选择以真实成曲比较为依据。

01 留住期待压力；02 既享受被看见也需要被认识；03 充电器与衣服细节可懂；04 same love 与关镜头同时成立；05 有悲伤也有笑；06 保留幽默而非卡通声；07 能听见仍在选择和工作的含义。

准确 BPM/调性与时长以实际音频核查，计划值留在单独字段。若改了歌词、Hook、配器源或段落，递增版本并同步记录。音频参考是否复现了原动机，由对照确认；不能因为提示写了 preserve 就标通过。

## C — 录音、混音与母带

当前均 PENDING AUDIO。

- 保存原始下载、source dry、编辑版与 final，不覆盖原件。实际源若低分辨率，升采样不能变成更高原生质量。
- 新录制工程可用 24-bit PCM、44.1 或 48 kHz 等合适规格，最终按实际分发渠道要求交付。每个版本记录真实格式，不能从文件扩展名猜位深。
- 原始隔离多轨与算法分离 stems 分开标记；分离素材有渗漏或伪影就如实记录。工程 stems 共同起点、相同长度与采样率，保留尾音。
- 实测 LUFS-I、dBTP、LRA、时长、声道、采样率与位深。听非预期削波、齿音、低频相位、808 遮挡、采样接缝、突兀尾切。
- 在耳机、可靠监听、手机/小音箱、单声道检查，并做有损编码预览。采样库失真与艺术性削波由听感目的判断，不只看峰值。
- 专辑动态应保留 05 的克制与 06 的明亮冲击，不机械把七首压成同一响度。

[Spotify 官方说明](https://support.spotify.com/au/artists/article/loudness-normalization/)解释播放归一化，给出 -14 LUFS-I、低于 -1 dBTP 的优化建议；更响的 master 建议低于 -2 dBTP。本包把它列作平台建议，不将单一数值当作所有 hip-hop 的行业审美标准。最终以听感、编码和实际渠道规格共同判断。

## D — 署名与发行

当前均 PENDING CONTRIBUTORS / PENDING DISTRIBUTION。

确认真实主艺人、客串、词曲作者、制作人、演奏者、录音/混音/母带人员及书面分成。角色 M1/F1/F2 是制作代号，不能填成真实发行人名。样本登记真实来源、录音所有者与适用使用条件；生成素材保存生成记录及当时账户适用条款。

发行歌词以最终音频为准，删制作标签，实际同步时间戳在音频定稿后制作。ISRC/UPC 不自行编造，交由实际发行流程处理；[IFPI 说明](https://isrc.ifpi.org/why-use-isrc/when-to-assign)新的或实质改变的录音需要独立 ISRC。曲名、版本名、明确内容标记与封面保持一致。

每阶段签核需真实人员、版本、日期与问题处理记录。同一独立制作人可以兼任多角色，但不能用技术脚本的 PASS 代替人声、混音或发行审听。
