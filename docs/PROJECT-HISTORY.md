# 项目需求与过程记录

本文件是对话成果与决策的归纳，不是逐字聊天记录。

## 需求

以 Lil Tjay《Born 2 Be Great》及专辑《Destined 2 Win》为研究起点，理解创作背景、歌词含义、生活启示与艺人魅力。最终创作一首英文 American hip-hop / melodic trap：Verse 要有具体细节与深意，句式丰富；Hook 要突出反复、记忆点与旋律性。

用户明确要求放弃中文旋律说唱方向，关注美国 hip-hop、trap、melodic trap 的内容和文化。beat 可自行选择。

## 阶段与状态

1. **研究与方向修正。** 整理官方发行信息、艺人访谈、美国 hip-hop 与 Atlanta trap 的文化及制作资料。先前中文歌曲文件按用户要求删除，本次不恢复。
2. **英文原创。** 写出《STILL GOT ME》完整歌词、叙事、Hook 元音韵脚与全曲编排建议。采用独立创作的 Hook 音符和 beat 草图；现有文件不是原曲旋律或伴奏的转录。
3. **Hook 工程草图。** 生成两个约 29 秒的 WAV（纯伴奏、含合成乐器旋律的导唱）、6 轨 MIDI、68 个音节事件的 CSV 及参数检查记录。
4. **男女声实验。** 用户希望比较 Halsey / Lil Tjay 方向的人声与 beat 的效果。实际可用接口只提供语音合成，制作使用公共库存语音 Aria / Shaun，并通过 WORLD 按音符重新合成音高与时值。生成混音、分轨、源语音、对齐记录与脚本。
5. **用户否定实验。** 用户明确认为合成人声效果糟糕，要求尝试两位艺人的真实演唱录音。此后不再将这些实验称为认可的成品。原参数检查只证明时长、音量和数据有效，不能证明听感良好。
6. **真实人声方向未完成。** 找到 Lil Tjay 与 Halsey 的官方 YouTube 页面，保留参考链接；未取得或制作真实原唱的混音文件。仓库不包含这些艺人的录音或克隆模型。
7. **归档。** 2026-09-13，用户要求把本对话所有资产整理上传至 `Royal44-k/Lil-Tjay-Type-Lyrics`。保留 31 个既有交付资产，附目录索引、来源、复现与校验工具。
