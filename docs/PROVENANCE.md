# Material provenance

This repository is a creative-project archive requested by its owner. It is not affiliated with Lil Tjay, Halsey, their labels, or their representatives.

| Material | Provenance |
| --- | --- |
| STILL GOT ME lyrics | English lyrics generated during the conversation for a fictional narrator. |
| Hook score and MIDI | Original composition decisions from the conversation; not a transcription of Born 2 Be Great. |
| Instrumental WAV files | NumPy synthesis produced by the included original rendering script. No artist recording was sampled. |
| Female speech source | HeyGen public stock voice Aria; generated reading of the original Hook text. |
| Male speech source | HeyGen public stock voice Shaun; generated reading of the original Hook text. |
| Experimental sung mixes | Stock speech resynthesized with WORLD and mixed with the original instrumental. Rejected by the user for poor sound quality. |
| Research | Short notes and attributed interpretations linked to external sources; no full original-song lyrics or artist recordings are stored. |

The metadata preserves stock voice names/IDs, original durations and word timestamps. Provider delivery URLs and request IDs are omitted from the GitHub archive. The audio files themselves are included, so reproduction does not require access to a provider account or expired link.

The files named `vocal-female-source.wav` and `vocal-male-source.wav` in the original session contained MPEG audio. In this archive those byte-identical originals are correctly named `.mp3`; the separately generated `-source-pcm.wav` files are actual PCM WAVs.
